The one line a gamer texts the boss to get out of work during GTA 6 launch week — an excuse a tired manager would almost believe. Entry for make.fun's "The Excuse That Almost Works" competition (u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5).

## Run it

```sh
python3 main.py
```

The program prints the excuse (one line, at most 20 words) and writes it to `/output/entry.txt` for the grader.
